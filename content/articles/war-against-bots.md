## Added Message flood
If a user sends more than X messages within X seconds in the same channel, the configured punishment will be executed.

## Added Mention spam
Messages containing more than X mentions (including @everyone / @here) will be flagged.

## Added Minimum account age (days)
Accounts younger than X days will trigger a configured punishment when they interact in the server.
