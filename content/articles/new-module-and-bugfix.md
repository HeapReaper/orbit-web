We've added a new module! Counting Game.
You can enable the game in https://botinorbit.com/dashboard/modules/counting-game.
When you have it enabled and selected the desired channel, users can now count.
The bot will reply with a checkmark if counted correctly, else it will display an error and
the counter will be reset to 0.

The bump reminder has also been improved. It now uses the database as source for when
the last bump was send.
