## Lichess
We've added a new module: Lichess.
This module is simulair to the Chess.com integration. It has the following commands:
- /lichess link
- /lichess unlink
- /lichess profile
- /lichess stats

## NumberGuess improvements
We've added two new options to the /numberguesser start command:
- /numberguesser start <min> <max> <description> <cooldown>

The descriptions adds text to the start notification.
In the cooldown you can add the amount of seconds to limit the amount of guesses in a
particulair time.
