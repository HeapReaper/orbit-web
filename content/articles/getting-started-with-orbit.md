## Introduction

Welcome to Orbit! This guide will walk you through everything you need to know to get started with the most powerful Discord bot for server management.

## Adding Orbit to Your Server

1. Go to the [Orbit website](https://botinorbit.com) and click **Add to Discord**
2. Select the server you want to add Orbit to
3. Grant the required permissions
4. Click **Authorise**

Orbit will join your server immediately and is ready to configure.

## Setting Up Your First Module

Head over to the [dashboard](https://botinorbit.com/dashboard) and select your server. You'll see all available modules listed there.

### Welcome Messages

The **Auto Message** module lets you greet new members automatically:

1. Enable the module in your dashboard
2. Select the channel where welcome messages should be sent
3. Customize the message using the built-in editor
4. Save your changes

### Auto Role

Automatically assign roles to new members when they join:

1. Enable **Auto Role** in the modules list
2. Pick one or more roles to assign
3. Save — that's it!
